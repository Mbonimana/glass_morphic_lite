# glass_morphic_lite

A lightweight, performance-optimized glassmorphic (frosted glass) container widget for Flutter. Built using native Flutter components with zero third-party dependencies.

## Features

* **High Performance**: Optimized to reduce GPU overhead.
* **Highly Customizable**: Easily adjust blur, background opacity, colors, custom gradients, and borders.
* **Lightweight**: Zero external dependencies to keep your application's bundle size minimal.
* **Multiplatform**: Fully supports Android, iOS, Web, macOS, Windows, and Linux.

## Getting Started

Add `glass_morphic_lite` to your `pubspec.yaml`:

```yaml
dependencies:
  glass_morphic_lite: ^1.0.0
